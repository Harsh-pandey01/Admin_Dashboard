## DashPro - Admin Dashboard

### It is an modern Admin dashboard build using modern stack .

- React 
- Tailwind CSS 
- Rechart ( for charts )
- Tanstack Table 
- Redux 


Following are some features of the DashPro -

- Responsive for every devices .
- Dark / Light Theme .
- Mordern UI .
- Scalable Tables and charts .
